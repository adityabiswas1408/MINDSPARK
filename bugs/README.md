# Bug Traces (`bugs/`)

This directory stores structured trace records for non-trivial bugs worth reconstructing later.

## Trace Template (`bugs/<slug>.md`)
```markdown
# Bug: <short description>

**Status:** open / fixed
**Found:** <YYYY-MM-DD>

## Reproduction
<minimal steps to trigger>

## Root cause
<underlying technical cause>

## Fix
<what changed and why>

## Verification
<command/output proving resolution>
```
