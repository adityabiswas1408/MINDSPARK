=== SECTION 1: WHAT YOU ARE BUILDING ===

Build a single self-contained HTML file named index_mobile.html.

This file is a MOCKUP VIEWER — a desktop-accessible HTML page that displays 
every screen of the MindSpark web application as it would appear on a mobile 
phone (390px wide, iPhone 14 proportions).

MindSpark is a web-based mental arithmetic assessment platform for an abacus 
institute. It has two portals:
- Student Portal: Students take Flash Anzan exams and view results
- Admin Portal: Teachers manage students, create exams, monitor live sessions

The viewer shows each screen inside a phone frame rendered on a desktop page.
Clicking "Jump to screen" dropdown navigates between screens.


=== SECTION 2: ANTI-HALLUCINATION RULES ===
READ THESE BEFORE WRITING A SINGLE LINE OF CODE.

RULE 1 — NO PLACEHOLDERS EVER
Do NOT write any of these: [content here], <!-- TODO -->, 
[screen content], placeholder text, lorem ipsum, "..." as content,
or any shortened stub. Every screen must be FULLY rendered.

RULE 2 — COLOUR LOCK
The ONLY hex colours permitted in this file are listed in SECTION 5.
Do NOT invent colours. Do NOT use rgb(). Do NOT use named colours like 
"green" or "red". If you need a shade not on the list, use the nearest 
listed value. This rule has zero exceptions.

RULE 3 — FONT LOCK
Use ONLY 'DM Sans' (all UI text) and 'DM Mono' (numbers, timers, 
roll numbers, monospace data). Both are imported from Google Fonts.
Do NOT use system-ui as the primary font. Do NOT use any other typeface.

RULE 4 — COMPLETE EVERY SCREEN
The file must contain ALL 38 screens listed in SECTION 7, in order.
After you write each screen's closing div, add this exact comment:
<!-- SCREEN-COMPLETE: [screen-id] -->
If this comment is missing, the screen is incomplete.

RULE 5 — NO EXTERNAL DEPENDENCIES
No CDN links, no npm, no external JS, no icon font CDN.
ONLY allowed external: the single Google Fonts @import link.
All icons are inline SVG paths written directly in the HTML.
All styles are in a single <style> block in <head>.

RULE 6 — NO IFRAMES
Every screen is inline HTML inside a .phone div. No iframes, no 
data-srcdoc, no srcdoc. All content is direct child HTML.

RULE 7 — REAL DATA ONLY

RULE 8 — CSS NAMESPACE SCOPING
Every screen's content div has class "s-[screen-id]" on the outer wrapper.
Screen-specific CSS must be scoped: .s-[screen-id] .component { ... }
Shared components go in the global shared CSS block.

RULE 9 — MOBILE PATTERNS ONLY
No horizontal sidebars. No desktop nav rails. No tables wider than 
the phone frame. Use ONLY these mobile navigation patterns:
  Students: Bottom tab bar (4 tabs: Home, Exams, Results, Profile)
